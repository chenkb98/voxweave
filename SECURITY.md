# Security

The latest patch release is the supported version. Default workflows operate on
local files and synthetic fixtures. Input schemas reject unknown fields and
non-finite numeric values where persisted.

Do not put access tokens, personal recordings or confidential transcripts into
public issues. For sensitive defects, use GitHub private vulnerability reporting
when it is enabled. Include a minimal synthetic reproduction and package version.

Keep dependency versions current and review the trust and licensing requirements
of any external model or dataset before loading it into your environment.
