# 语音流与对话架构

```text
PCM bytes → stream → turns → conversation → backend → events
```

`audio` 是独立的 NumPy 音频边界：数组统一为帧×声道，WAV/PCM16 转换显式处理
采样率、声道、量化和不完整帧。上层模块不依赖隐藏的全局随机状态。

PCM 解码、音频帧与对话轮次各有独立边界。离线后端只验证协议，真实模型通过显式接口注入。

## 数据契约

公共 API 和持久化字段通过完整快照或穷举测试约束。错误路径在可行时保持
输入和已有状态不变。默认例子使用合成数据，不要求 GPU、外部服务或模型权重。
