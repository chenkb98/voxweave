# backend


## `model_request`

创建厂商无关的推理请求，限定生成参数并要求最新消息来自用户。请求复制历史，后端修改参数或内容不会影响会话存档。

## `offline_response`

离线后端仅报告音频片段数、时长和文本字符数，便于验证端到端协议。它明确标注为测试后端，不识别语义，也不模仿预训练模型的回答。

## `stream_response`

按 Unicode 码点分块文本，不拆分 UTF-8 字节。每次响应恰有一个终结事件，空回答也有可观察的终结标记。

## `run_conversation`

把音频分帧、语音轮次、用户消息和后端回复连接起来。默认后端离线运行，真实模型可通过明确的可调用接口注入。
