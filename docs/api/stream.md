# stream


## `byte_chunks`

按网络字节块大小分割载荷，保留最后的短块。字节分块不等同于 PCM 帧分块，解码器需要处理跨块采样。

## `PCMDecoder`

增量解码器暂存不足一个完整 PCM 帧的字节。任意网络分块边界均应得到相同音频；结束时未完成的帧会报错，并保留状态以便补齐。

## `AudioFramer`

把任意大小音频包转换成固定帧长，尾部可保留实际长度或显式补零。声道数在流中不能改变，错误输入不会改变已有缓冲状态。

## `RingBuffer`

容量以帧计算，满载时可拒绝输入或丢弃最旧帧。拒绝路径保持缓冲不变；读取也需完整满足请求，避免悄悄丢样本。

## `SampleClock`

用整数采样位置计时，秒数始终由位置除以采样率获得，避免每个小块累加浮点时长产生漂移。快照只保存采样率和位置。

## `JitterBuffer`

按序号恢复乱序字节包，只有连续数据才会输出。覆盖完整到达顺序排列；重复、过期、满载及缺包结束均有明确错误。
